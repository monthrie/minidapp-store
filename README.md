# Monthrie MiniDapp Store

This repository hosts a MiniDapp store for the Minima ecosystem, featuring premium MiniDapps.

## Adding this Store to Minima

To add this store to your Minima app:

1. Open the Minima app
2. Navigate to the DAPP Store
3. Click the + button
4. Enter the URL: `https://monthrie.github.io/minidapp-store/store.json`

## Current MiniDapps

- **VOX** (v2.0.0): The world's only censorship-proof social media protocol

## Repository Structure

- `/assets/` - Contains store and MiniDapp icons
- `/dapps/` - Contains MiniDapp files
- `store.json` - Store configuration file
